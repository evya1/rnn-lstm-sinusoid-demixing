# RNN-LSTM Sinusoid Demixing

Exercise 01 project for comparing Fully Connected, RNN, and LSTM models on reconstructing clean sinusoidal components from noisy composite sinusoidal signals.

## Project Goal

The project will generate synthetic sinusoidal signals, combine them into a noisy mixed signal, and train neural network models to reconstruct a selected clean sinusoidal component using a one-hot selector.

## Planned Components

- Synthetic sinusoid generation
- Noise injection
- Dataset construction using context windows
- Fully Connected, RNN, and LSTM models
- Training and evaluation pipeline
- Visualizations and comparative analysis
- Documentation in `docs/PRD.md`, `docs/PLAN.md`, and `docs/TODO.md`
